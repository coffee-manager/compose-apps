앱오더 자동수락

앱오더·배민·쿠팡·요기요 주문이 들어오면 포스기가 알아서 수락합니다. 손님 응대 중에도, 음료 만드는 중에도 주문을 놓치지 않아요.

이런 점이 좋아요

메모리 사용량을 1/10로 줄였어요

프로그램을 처음부터 새로 만들었습니다. 오래된 윈도우7 포스에서도 가볍게 돌아가요.

자동수락이 안 눌리던 매장도 이제 됩니다.

주문 알림에 뛰어가지 않아도 돼요

앱오더 창이 닫혀 있어도 주문이 오면 창을 열어 수락합니다. 배민·쿠팡·요기요 배달 주문도 같이 받아요.

창 가운데 버튼을 한 번 누르면 잠시 멈추고, 다시 누르면 이어서 동작합니다.

우리 매장에 맞게 바꿔요

앱오더·배민 포장·배민 배달·쿠팡·요기요를 따로 켜고 끕니다. 쿠팡 조리시간(바로 수락·5분·10분 추가), 영업시간에만 수락, 자동으로 포장 완료할 주문 개수도 정할 수 있어요.

배민·쿠팡·요기요 배달 자동수락을 새로 넣었어요.

켜는 걸 잊어도 괜찮아요

Windows가 켜질 때 함께 실행되고, 창을 닫아도 화면 오른쪽 아래 트레이에서 계속 동작합니다. 시작할 때 창을 숨길 수도 있어요. 모두 옵션에서 바꿀 수 있습니다.

설치 방법

포스기에서 순서대로 따라 하세요. 3분이면 끝나요.

  1. 포스기에서 이 페이지 열기

    포스기 인터넷 창 주소창에 아래 주소를 입력하고, 목록에서 앱오더 자동수락을 누르세요.

    https://coffee-manager.github.io/compose-apps

  2. [설치 파일 받기] 누르기

    compose-apporder-setup.exe 파일이 내려받아집니다.

    브라우저가 “자주 다운로드되는 파일이 아닙니다”라고 하면 파일 옆 ⋯ → 유지를 누르세요.

  3. 받은 파일 실행

    다운로드 목록이나 ‘다운로드’ 폴더에서 파일을 두 번 누르세요.

    파란 Windows의 PC 보호 창이 뜨면 추가 정보 → 실행을 누르세요. 개인이 만든 프로그램이라 인증서가 없어서 나오는 안내예요.

  4. [다음] → [설치]

    관리자 권한은 필요 없어요. 기본으로 D:\AppOrderAuto에 설치됩니다. D 드라이브가 없는 포스기는 C:\AppOrderAuto에 설치돼요. 설치 화면에서 다른 폴더를 고를 수도 있어요.

  5. 바탕화면의 ‘앱오더 자동수락’ 실행

    ‘앱오더 자동수락 동작 중’ 창이 뜨면 끝입니다. 다음부터는 Windows가 켜질 때 알아서 실행돼요.

    예전 압축파일(zip) 버전을 쓰셨다면 트레이에서 예전 프로그램을 종료한 뒤 설치하세요. 설정은 그대로 이어지고, 예전 바로가기는 지워도 됩니다.

사용 방법

멈추기 / 다시 켜기

창 가운데 버튼을 누릅니다. ‘동작 중’이면 수락하고, ‘미 동작 중’이면 멈춘 상태예요.

설정 바꾸기

창 위 메뉴의 [옵션]을 눌러 바꾸고 [저장]을 누르세요.

창이 안 보일 때

화면 오른쪽 아래 트레이(^)에서 아이콘을 두 번 누르면 창이 다시 열려요. 완전히 끄려면 아이콘을 오른쪽 클릭 → Exit.

문제 해결

프로그램은 켜졌는데 주문이 자동수락되지 않아요

대부분 포스 프로그램이 관리자 권한으로 실행돼서 생기는 문제입니다. 옵션에서 바로 고칠 수 있어요.

  1. 창 위 메뉴 [옵션]
  2. ‘관리자 권한 실행’ 켜기 → [저장]
  3. 다시 시작할지 물으면 [예], Windows 권한 허용 창이 뜨면 [예]

권한 허용 창은 처음 한 번만 떠요. 그래도 안 되면 ‘영업시간에만 자동수락’이 켜져 있는지, 지금이 영업시간 안인지 확인해 주세요.

배민 포장 주문만 수락되지 않아요

작업표시줄이 ‘자동 숨기기’ 상태면 배민 포장 알림을 찾지 못합니다. 작업표시줄을 오른쪽 클릭 → 작업 표시줄 설정에서 ‘자동으로 숨기기’를 끄고 고정해 주세요.

“이미 실행 중입니다”라고 나와요

이미 트레이에서 동작 중이에요. 화면 오른쪽 아래 트레이(^)에서 아이콘을 두 번 누르면 창이 열립니다.

쿠팡·요기요 주문만 수락되지 않아요

[옵션]에서 쿠팡·요기요 자동수락이 켜져 있는지 확인하세요.

주문 창이 다른 창에 가려져 있으면 누르지 않아요. 앱오더 자동수락 창이나 다른 창이 주문 창을 덮지 않게 옆으로 옮겨 주세요.
